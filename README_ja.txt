朝トレ - iPhone向け筋トレ記録PWA（無料ソース）

できること
・6種目のチェック
・今日の達成率
・連続達成日数と累計達成日数
・直近14日の記録
・朝の希望時刻の保存
・ホーム画面アプリとして起動するPWAの基本ファイル

重要：この版は記録機能が動く初期版です。データはiPhone内のブラウザ保存領域に保存します。
「朝の希望時刻」は設定として保存されますが、アプリを閉じている間の自動プッシュ通知はまだ実装していません。
iPhoneのWeb PushにはHTTPS公開、ホーム画面への追加、ユーザー操作による通知許可、プッシュ購読を保存するサーバー、通知送信処理が必要です。
Apple Developer Programへの加入はWeb Push自体には不要です。

iPhoneへの追加
1. このフォルダ一式をHTTPS対応の静的ホスティングに公開します（例：GitHub Pages）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」。
4. ホーム画面の「朝トレ」アイコンから起動します。

注意
・このZIPを展開しただけでは、ホーム画面に追加できる公開URLにはなりません。
・記録を消さないため、SafariのWebサイトデータを削除しないでください。
・運動中に痛みが出たら中止し、無理のない回数に調整してください。
